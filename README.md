# StarDroid

**Classic StarCraft and Brood War on Android.**

**Latest release: 1.5 · Android 8.0+ · ARM64 and x86-64**

[Download APK](https://github.com/kinopiowarrior/StarDroid/releases/download/v1.5/StarDroid-1.5.apk) · [Release notes](https://github.com/kinopiowarrior/StarDroid/releases/tag/v1.5) · [Source ZIP](https://github.com/kinopiowarrior/StarDroid/releases/download/v1.5/StarDroid-1.5-source.zip) · [Discord](https://discord.gg/F2FnjUrtQ)

## New in 1.5

- UMS support and common EUD support.
- Better custom-map compatibility, map audio, and language support.
- Improved AI expansion defense and transport recovery.
- Bot difficulty shown on the score screen.
- Game-data patch detection in App Options, including repacked archives.
- Additional gameplay and interface fixes.

## Features

- StarCraft and Brood War campaigns, briefings, and cinematics.
- Custom games with computer opponents and optional Hero Mode.
- Local multiplayer over Bluetooth, with optional Wi-Fi Direct.
- Touch, mouse, keyboard, and gamepad controls.
- Saves, replays, and map imports from `.scm`, `.scx`, and ZIP files.

## Install

1. Download and open **[StarDroid-1.5.apk](https://github.com/kinopiowarrior/StarDroid/releases/download/v1.5/StarDroid-1.5.apk)**.
2. Import your own `StarDat.mpq`, `BrooDat.mpq`, and `Patch_rt.mpq`.
3. Import `StarCraft.mpq` and `BroodWar.mpq` from the original installation media for campaigns and movies.

To update, install over the existing app **without uninstalling**. Use the same version on all multiplayer devices.

**Game data is not included.** This is an unofficial fan project, not affiliated with Blizzard Entertainment.
