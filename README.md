# StarDroid

**StarCraft and Brood War on Android, with Classic, Remastered and optional Carbot graphics.**

**Latest release: 1.8.1 · Android 8.0+ · ARM64 and x86-64**

[Download APK](https://github.com/kinopiowarrior/StarDroid/releases/download/v1.8.1/StarDroid-1.8.1.apk) · [Release notes](https://github.com/kinopiowarrior/StarDroid/releases/tag/v1.8.1) · [Source ZIP](https://github.com/kinopiowarrior/StarDroid/releases/download/v1.8.1/StarDroid-1.8.1-source.zip) · [Discord](https://discord.gg/F2FnjUrtQ)

## Features

- StarCraft and Brood War campaigns, briefings, cinematics, saves and replays.
- Classic, Remastered and Carbot artwork for supported battlefield and interface graphics.
- CPU/GPU rendering options, zoom, widescreen menus and enlarged group icons.
- Custom games with computer opponents and optional Hero Mode.
- Local multiplayer over Bluetooth, with optional Wi-Fi Direct.
- **UMS support and common EUD support.** EUD compatibility is partial; not every map or Windows-specific extension works.
- Touch, mouse, keyboard and gamepad controls, with guides in the Controls menu.
- Nine interface languages, map filtering, and ZIP/RAR imports.

## Fixed in 1.8.1

- Gamepad double-tap selection of matching units on screen.
- Mixed interface languages in briefing controls, tips and supported in-game labels.

Interface language changes app menus and labels. Campaign dialogue, story text, map-authored names/objectives and voices use the language of your imported files.

## Graphics

Remastered support covers units, terrain, menus, briefings, portraits and campaign artwork. Carbot / StarCraft Cartooned is available when its assets are included in your imported data.

In **App Options**, Classic / Remastered choices appear only when Remastered graphics are installed. The Remastered / Carbot choice appears only when usable Carbot data is installed. The existing SD/HD switch uses your selected HD artwork, including in supported multiplayer matches.

## Install

1. Install **[StarDroid-1.8.1.apk](https://github.com/kinopiowarrior/StarDroid/releases/download/v1.8.1/StarDroid-1.8.1.apk)**. To update, install over the existing app **without uninstalling**.
2. Import your own game data using either option below.
3. Import maps as `.scm`, `.scx`, ZIP or RAR files. Use 1.8.1 on all multiplayer devices.

**Classic files:** import `StarDat.mpq`, `BrooDat.mpq` and `Patch_rt.mpq`. Import `StarCraft.mpq` and `BroodWar.mpq` from the original installation media for campaigns and movies.

**Remastered / Carbot files:** import the installation folder, or a ZIP/RAR containing the **Data** folder and its matching **.build.info** file together. A complete installation can also supply supported Classic game content.

**Adding Carbot graphics:** if the Carbot option is missing, re-import your complete installation data once. The option appears only when the imported data contains usable Carbot assets.

**Game data is not included.** This is an unofficial fan project, not affiliated with Blizzard Entertainment.
