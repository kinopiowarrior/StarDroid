# StarDroid 1.9.5

- Fixed HD/GPU slowdown when viewing remembered buildings in fog after loading a save.
- Added **Player statistics** in App Options, using a normal Android text dialog for match results, game time, combat totals, resources and campaign progress.

Includes the larva-selection and Spore Colony fixes from 1.9.4.

Install over your current app without uninstalling. **Data imported since 1.9 remains valid; no reimport is needed.**

See [validation](../VALIDATION.md) for tested scope and device-testing limits.
