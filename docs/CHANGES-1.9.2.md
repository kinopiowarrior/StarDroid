# StarDroid 1.9.2

**Build 180 replacement:** corrected Disruption Web appearing dark with Enhanced Lighting enabled. Install over the earlier 1.9.2 build; no reimport is needed.

- Fixed stray shortcut letters in translated menu labels and Cyrillic campaign text.
- Improved third-party keyboard support. The keyboard overlays the game without shrinking its resolution.
- Added optional touch controls in unused side margins, shown only when there is enough room.
- Improved HD/Carbot group wireframes and control-group replacement.
- Localized campaign mission names using the installed campaign language.
- Fixed Remastered Protoss warp-in textures and cloud transparency for Disruption Web and Dark Swarm.
- Kept campaign unlocking in App Options.

Addresses [#10](https://github.com/kinopiowarrior/StarDroid/issues/10), [#11](https://github.com/kinopiowarrior/StarDroid/issues/11) and [#12](https://github.com/kinopiowarrior/StarDroid/issues/12).

Hold a control-group button for half a second to replace it with your current selection. Find the margin option under **Controls → Selection settings → Touch buttons in side margins**. Campaign unlocking is under **App Options → Campaign progress**.

Install over the current app without uninstalling. Existing imports, maps, profiles, progress, saves and replays are retained. **Data imported since 1.9 does not need to be imported again.** Local Bluetooth/Wi-Fi Direct multiplayer remains available.

Only Weave is bundled. Owned StarCraft game data and other maps must be imported separately. See [validation](../VALIDATION.md) for tested scope and device-testing limits.
