# Joining a Remastered PC on the same LAN

1. On the PC, open StarCraft: Remastered, choose Local Area Network (UDP), and host a standard Melee, Free For All, or Top vs Bottom game.
2. Connect Android to the same local network. Open Multiplayer, select Wi-Fi LAN, then choose Join Game.
3. Select the PC room and tap Join. An entry such as **1/4** means one player is present in a four-slot room. The PC host starts the match once the players are ready.

If the map is missing on Android, enable map sharing on the PC. StarDroid downloads it through the lobby, checks the file size, CRC and MD5, and saves it in the usual map collection. You can also import the same SCM or SCX beforehand. If Android already has the map, its local filename can differ.

Tap the race on your row in the multiplayer lobby to choose Zerg, Terran, Protoss or Random. The PC host sees Random as soon as the phone enters an open race slot. The roster follows the host, and the phone plays the imported countdown sound as the timer runs from five to zero. Unoccupied map slots can stay open. PC crossplay uses retail game rules. This release supports human players with the standard Remastered unit limits. For this mode, leave computer opponents and observers out and leave Use Original Unit Limits off. The room browser explains restrictions for other game types, EUD, saved PC sessions and PC replay rooms.

## During the match

Open **Game Menu → Pause Game** to pause for everyone. The screen turns black and white while paused. Either player can choose **Resume Game**. On a physical keyboard, the Pause key also toggles the shared pause. Simply opening or closing the menu keeps the match in its current state.

Use **Game Menu → Message** or press Enter to chat. For a private in-game message, type `/w 2 hello` for player slot 2, or replace the number with the player’s full name. Use `/r` followed by the message to reply to the last whisper. In-game sender names use their match colors. In-lobby chat goes to the room.
