# StarDroid 1.9.27

- Fixes campaign AI requests to establish an expansion at a specific resource area. In *Fury of the Swarm*, the renegade Zerg can occupy lost outposts and trigger the mission’s original transmissions and scientist objective.
- Install over your existing copy. Working imports carry over. If an old save is already stuck, restart *Fury of the Swarm* using the existing import.

The update also includes the [startup, Remastered import, SD-card and Normal skirmish changes from 1.9.26](CHANGES-1.9.26.md).
