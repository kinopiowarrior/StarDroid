# StarDroid 1.9.3

- **Large unit group icons** now appears and works only while Widescreen is enabled.
- Turning Widescreen off restores normal icons. Your saved large-icon choice is retained when you turn it on again.

Includes the latest 1.9.2 fixes for side-margin button alignment and Disruption Web with Enhanced Lighting.

Install over your current app without uninstalling. **Data imported since 1.9 remains valid; no reimport is needed.**

See [validation](../VALIDATION.md) for tested scope and device-testing limits.
