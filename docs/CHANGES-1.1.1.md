# StarDroid 1.1.1

Bug fixes and interface improvements following 1.1.

- Improved AI expansion placement, island construction, base defenses, Terran
  repairs, worker defense and transport loading. Detector responses use nearby
  available units and leave others available elsewhere.
- Fixed mouse right-click gathering/attacking and Unload with mixed empty/loaded
  transport selections.
- Corrected kill counts, Broodling/hallucination lifetime displays and the
  Queen's redundant Parasite research option.
- Fixed production portraits, rescued-unit colors, trap animations and scripted
  burrowed ambushes. Includes the Dunes of Shakuras script and Assimilator
  resource-display fixes. Zerg mission 3 is titled The New Dominion.
- Added automatic interface-language detection from imported game text.
- Command buttons and control groups can be resized separately.
- One Smooth graphics (game + UI) option controls the battlefield, menus, HUD,
  portraits and other game artwork. It defaults to ON for new installs.

Download **StarDroid-1.1.1.apk** and install over the existing app without
uninstalling. Game data is not included. The source ZIP is for development.
Use the same version on all multiplayer devices. Older replays require their
matching older build; existing single-player saves and settings are retained.

Targeted automated tests, compilation, signing and alignment checks passed.
Physical Android testing and full campaign playthroughs remain unverified.
Spanish detection was tested with sample text, not an actual Spanish install.
The reported Infested Terran supply double count could not be reproduced and is
not claimed fixed.
