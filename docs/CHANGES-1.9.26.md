# StarDroid 1.9.26

- StarDroid saves campaign voice availability for repeat launches. The startup report in Credits shows whether the inventory was reused or rebuilt.
- Remastered installation folder imports support providers that hide build metadata in directory listings. Seekable game files can be read directly, and providers that require copying use temporary space on the selected game-data volume.
- New Remastered imports use the selected game-data volume for the installed graphics as well. Existing split-storage installs can still load their graphics. The folder importer also reuses each base campaign check across languages, reducing repeated map reads.
- In new Normal skirmishes, each computer opponent waits at least 3,600 simulation frames between strategic attack launches. Its expansions and reserve forces share that timer. Terran mixed waves request up to two Firebats when Marines are available. Android multiplayer peers need build 207 to play together.
- Credits keeps the startup report and Copy button and removes the performance and AI recording checkbox.
