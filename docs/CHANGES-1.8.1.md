# StarDroid 1.8.1

- Double-tap the gamepad selection button (A by default) over a unit to select matching units on screen, like mouse double-click selection. Drags, commands and menu interactions do not count as a double tap.
- Apply the selected interface language to briefing controls, tips and supported in-game labels, even when imported game files use another language.

These changes address [issue #7](https://github.com/kinopiowarrior/StarDroid/issues/7) and [issue #6](https://github.com/kinopiowarrior/StarDroid/issues/6).

Install over your existing app without uninstalling. Existing game data, settings, saves and the 1.8 multiplayer/replay formats remain compatible. No data re-import is needed for these fixes.

The interface language controls app menus and interface labels. Campaign dialogue, story text, map-authored names/objectives and voices retain the language of the imported content. Import that content in your preferred language to change it.

The APK and matching source ZIP include both ARM64 and x86-64 support. Focused regression tests and build checks are recorded in the source archive. Physical Android controller testing was not performed for this update.
