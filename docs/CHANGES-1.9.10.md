# StarDroid 1.9.10

- Developer source downloads now receive a clear explanation when selected as game data.
- Test files from the developer source are rejected before they can replace working imported data.
- The patch diagnostic identifies known developer test data already imported and explains how to replace it.
- Clearer import guidance distinguishes StarCraft game files from the app's developer source and explains the patch diagnostic.

The reported “Invalid or unsupported patch” text is a read-only version diagnostic. This update improves input validation and guidance; it does not change supported native patch formats. The reporter's selected file was not supplied.

Retains the import fixes from 1.9.9, Remastered graphics fixes, minimum/maximum zoom settings and earlier normal-build fixes.

Install the APK over your current app without uninstalling. **Valid data imported since 1.9 remains usable; no reimport is needed.** The developer source ZIP is not game data.
