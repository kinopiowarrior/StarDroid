StarDroid 1.9.2 — Android version code 180

Pinned JDK 17, SDK 35, Build Tools 35 and NDK r27d. Java targets version 8.

Build the Android APK:
1. python3 scripts/setup_toolchain161.py
2. Run the focused current checks described in VALIDATION.md.
3. python3 scripts/build_native_webfix180.py
4. python3 scripts/package_webfix180.py --baseline-source /path/to/StarDroid-1.9.1-source.zip --rebuilt-native
5. python3 scripts/sign_webfix180.py --config /external/private/signing.json --output /external/output/StarDroid-1.9.2.apk

The native build first reproduces native-engine from the pinned archive and
shipped patches, then builds both Android ABIs from frozen inputs. The packager
requires this fresh build receipt and verifies the exact baseline supplied.

is not required to build the APK using the public 1.9.1 baseline above.
